# Code of conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

**Expected.** Be kind and specific. Critique the work, not the person. Assume good faith, and say plainly when you disagree. Welcome newcomers; a question asked twice is a documentation bug.

**Not accepted.** Harassment, insults or personal attacks; sexualised language or imagery; publishing someone's private information; sustained disruption; anything you would not say to a colleague's face.

**Scope.** Issues, pull requests, discussions, and any space where you represent the project.

**Reporting.** Contact the maintainer privately through GitHub (the profile of the repository owner) or GitHub's reporting tools. Reports are handled confidentially. The maintainer may warn, remove content, or ban a participant, in proportion to the harm done.
